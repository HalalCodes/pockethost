🚀 PocketHost Studio - Multi-Repo GitHub Host Engine
PocketHost Studio হলো একটি মোবাইল-ফ্রেন্ডলি স্ট্যাটিক ওয়েবসাইট এবং ইমেজ হোস্টিং ইঞ্জিন, যা GitHub REST API এবং GitHub Pages প্রযুক্তি ব্যবহার করে কাজ করে। এর মাধ্যমে সরাসরি GitHub-এ ম্যানুয়ালি প্রবেশ না করেই আপনার ব্রাউজার বা মোবাইল অ্যাপ থেকেই ফাইল ও ছবি হোস্ট করা যায়।

💡 প্রজেক্টের মূল সুবিধাসমূহ (Key Features)
১. মাল্টি-রিপোজিটরি ম্যানেজমেন্ট (Multi-Repo Support):
১ জিবি ফ্রিতে হোস্টিং সীমার দ্বারপ্রান্তে পৌঁছালে নতুন রিপোজিটরি যুক্ত করে ১ ক্লিকেই স্যুইচ করা যায়।
নতুন রিপোজিটরিতে মূল অ্যাপ কোড আপলোড করতে হয় না।
২. ডাইনামিক ফোল্ডার সিস্টেম (Folder Directory):
কাস্টম ফোল্ডার তৈরি করার সুবিধা।
যেকোনো ফাইল বা ছবি আপলোড করার সাথে সাথে ফোল্ডারের অভ্যন্তরীণ ডেডিকেটেড .gitkeep ফাইল স্বয়ংক্রিয়ভাবে মুছে যায়।
৩. নিরাপদ ডিলিট মোডাল (5-Sec Safety Delete):
ভুলবশত ডিলিট হওয়া রোধে ৫ সেকেন্ডের একটি অ্যানিমেটেড কাউন্টডাউন ও ক্যানসেল অপশন চালু রয়েছে।
৪. ইমেজ ও এইচটিএমএল হোস্ট (Direct CDN & Pages):
গ্যালারি থেকে ছবি আপলোড করে ডাইরেক্ট ইমেজিং লিংক (https://.../picture/myphoto.jpg) পাওয়ার সুবিধা।
এইচটিএমএল কোড বা ফাইল আপলোড করে তাৎক্ষণিক লাইভ লিংক পাওয়ার সুবিধা।
⚙️ এটি কীভাবে কাজ করে? (How It Works)
এটি সম্পূর্ণ ব্রাউজার সাইড (Client-side) প্রযুক্তি দিয়ে তৈরি, যা GitHub API-এর সাহায্য নেয়:
[ইউজার ইন্টারফেস] ──(GitHub API + Token)──> [GitHub Repository] ──> [GitHub Pages Host]


১. সেটিংসে GitHub সংযোগ:
GitHub অ্যাকাউন্ট থেকে একটি Personal Access Token (Classic) তৈরি করতে হবে (পারমিশন স্কোপ: repo)।
অ্যাপের Settings ট্যাবে গিয়ে আপনার Username এবং Token সেভ করতে হবে। এটি ব্রাউজারের localStorage-এ সুরক্ষিত থাকবে।
২. ফোল্ডার ও ফাইল নির্বাচন:
Folders সেকশনে গিয়ে নতুন ফোল্ডারের নাম দিয়ে ফোল্ডার তৈরি করুন।
Deploy বা Image সেকশনে ড্রপডাউন থেকে কাঙ্ক্ষিত ফোল্ডারটি নির্বাচন করুন এবং ফাইলের নাম লিখুন।
৩. অটোমেটিক হোস্টিং ও লিংক জেনারেট:
ফাইল পাঠালে GitHub API মাধ্যমে সেটি সরাসরি আপনার রিপোজিটরির নির্দিষ্ট ফোল্ডারে জমা হয়।
ফাইলটি প্রস্তুত হওয়া মাত্রই অ্যাপটি আপনার জন্য কাস্টম ডাইরেক্ট লাইভ ইউআরএল তৈরি করে দেয়:
ফাইল লিংক: https://<username>.github.io/<repo>/<folder>/<filename.html>
ছবি লিংক: https://<username>.github.io/<repo>/<folder>/<imagename.jpg>
